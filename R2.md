# Publishing a depot to Cloudflare R2

R2 is the recommended host: zero egress fees at any volume, 10 GB on the free
tier, and correct CORS — which this needs, because a texture served without
`Access-Control-Allow-Origin` taints the canvas and breaks screenshot and video
export.

## What you have to do yourself

These steps need your Cloudflare account and API credentials, so they cannot be
scripted for you:

1. **Enable R2 on the account.** Dashboard → R2. This is the one genuinely
   manual step: it needs the terms accepted and a payment method, even for the
   free tier. Everything after it is scriptable.

   ```bash
   wrangler r2 bucket create <bucket>
   ```

2. **Give it a public URL.**

   ```bash
   wrangler r2 bucket dev-url enable <bucket>
   ```

   The `r2.dev` subdomain is rate-limited and Cloudflare does not intend it for
   production traffic — fine for proving things out. For real use attach a
   custom domain: `wrangler r2 bucket domain add <bucket> --domain <host>`.

3. **Set CORS.** Bucket → *Settings* → *CORS policy*:

   ```json
   {
     "rules": [
       {
         "allowed": { "origins": ["*"], "methods": ["GET", "HEAD"], "headers": ["*"] },
         "maxAgeSeconds": 3600
       }
     ]
   }
   ```

   Note the shape: wrangler wants `rules[].allowed.{origins,methods,headers}`,
   not the `AllowedOrigins`/`AllowedMethods` form Cloudflare's own R2 docs show
   — that one is rejected.

   Or skip the dashboard entirely:

   ```bash
   wrangler r2 bucket cors set <bucket> --file cors.json
   ```

   Narrow `origins` to your own sites if you prefer; it must not be omitted.
   Without it every textured canvas is tainted and export throws.

   CORS is request-driven, so `curl` shows no header unless you send one:
   `curl -I -H "Origin: http://localhost:3001" <url>`. A bare curl showing no
   `Access-Control-Allow-Origin` does not mean CORS is broken.

4. **Create an API token.** R2 → *Manage API tokens* → *Create*, with
   **Object Read & Write** on that bucket. You get an access key id and a secret.

5. **Configure rclone** with those credentials — `rclone config`, choose
   `s3` → `Cloudflare R2`. The secret is entered by you, into rclone, and is
   never stored in this repo.

   ```
   [r2]
   type = s3
   provider = Cloudflare
   access_key_id = <yours>
   secret_access_key = <yours>
   endpoint = https://<account-id>.r2.cloudflarestorage.com
   ```

## Then

```bash
./src/sync.sh ../shaderlibrary-assets r2:your-bucket/v1
```

The script refuses any depot not marked `"public": true`, and verifies the
manifest against `dist/` before uploading — so it cannot publish a bucket that
404s per frame.

Finally set that depot's `baseUrl` in `depot.json` to the bucket's public URL
and rebuild the manifest (`npx depot <depot> --manifest-only`).

## Backing up the masters

`packs/` holds the lossless sources, and they are deliberately not in git. R2 is
the natural place for them — but into a **separate, non-public bucket**, since
some depots' sources are licensed for use and not redistribution:

```bash
rclone sync ../shaderlibrary-assets/packs r2:your-backups/shaderlibrary-assets/packs
```

Both depots' sources together are well under the 10 GB free tier.
